How to play

Fill the grid so every row, column and 3×3 box contains 1–9 exactly once. Use pencil marks for candidates. The timer stops the moment the grid is correct.

Controls

  • ClickSelect a cell
  • 1–9Enter a number
  • BackspaceClear cell
  • NToggle pencil mode
  • ArrowsMove selection
